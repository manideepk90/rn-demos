# Hello World Demo

A simple "Hello World" React Native demo to demonstrate the basic structure and setup of demos in this repository.

## ✨ Features

- Basic React Native app structure
- Simple text display
- Demonstrates the minimal setup required

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI or React Native CLI

### Installation

1. Navigate to this demo directory:
   ```bash
   cd demos/hello-world-demo
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

### Running the Demo

```bash
# For Expo
npx expo start

# For React Native CLI
npm run android  # for Android
npm run ios      # for iOS
```
